# Dự án: Mô phỏng giao diện và kiểm thử đặt vé máy bay

## Giới thiệu

Dự án này nhằm mô phỏng quy trình đặt vé máy bay thông qua giao diện người dùng, đồng thời xây dựng các test case cơ bản để kiểm thử giao diện và chức năng.

## Nội dung file

File Excel `Trương Ngọc Bảo Linh_Mua vé máy bay.xlsx` bao gồm:

- **UI**: Mô tả các thành phần chính của giao diện đặt vé như: lựa chọn loại vé (một chiều/khứ hồi), ô nhập nơi đi, nơi đến, ngày đi, nút tìm kiếm,...
- **Nháp**: Phân tích sơ bộ, ghi chú các bước triển khai và các yếu tố liên quan đến hành trình người dùng.
- **Test case**: Danh sách test case bao gồm:
  - **Test ID**
  - **Precondition** (Điều kiện tiền đề)
  - **Steps** (Các bước kiểm thử)
  - **Expected Result** (Kết quả mong đợi)
  - **Test Result**, **Priority**, **Platform**,...

## Mục tiêu

- Hỗ trợ học tập và thực hành viết test case cho UI.
- Phát triển kỹ năng phân tích yêu cầu và kiểm thử giao diện người dùng.

## Hướng dẫn sử dụng

1. Tải file Excel từ repository.
2. Mở bằng Excel hoặc Google Sheets để xem các mô tả và test case.
3. Có thể mở rộng thêm test case hoặc mô phỏng giao diện bằng công cụ như Figma hoặc HTML/CSS.
